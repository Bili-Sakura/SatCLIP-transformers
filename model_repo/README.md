# Hugging Face Model Repositories

This directory contains Hugging Face Hub–style model repositories for SatCLIP checkpoints.

Each subdirectory is a self-contained model repo that can be uploaded to the Hub. Inference requires only `transformers` (plus optional `timm`/`torchgeo` for MoCo vision backbones) — not the original Lightning training code.

## Layout

```
model_repo/
└── SatCLIP-<Backbone>-L<resolution>/
    ├── README.md
    ├── config.json
    ├── preprocessor_config.json
    ├── model.safetensors          # generated by conversion script
    └── satclip/                   # custom code (auto_map / trust_remote_code)
```

## Available templates

| Directory | Vision encoder | L |
| --- | --- | --- |
| `SatCLIP-ResNet18-L10` | MoCo ResNet18 | 10 |
| `SatCLIP-ResNet18-L40` | MoCo ResNet18 | 40 |
| `SatCLIP-ResNet50-L10` | MoCo ResNet50 | 10 |
| `SatCLIP-ResNet50-L40` | MoCo ResNet50 | 40 |
| `SatCLIP-ViT16-L10` | MoCo ViT-B/16 | 10 |
| `SatCLIP-ViT16-L40` | MoCo ViT-B/16 | 40 |

Additional variants (`ResNet18-L40`, `ResNet50-L10`, `ResNet50-L40`, `ViT16-L10`, `ViT16-L40`) can be generated from checkpoints using:

```bash
python scripts/convert_ckpt_to_hf.py <checkpoint.ckpt> model_repo/<ModelName> --preset <ModelName>
```

## Publishing to the Hub

```bash
pip install huggingface_hub
huggingface-cli upload microsoft/SatCLIP-ResNet18-L10 model_repo/SatCLIP-ResNet18-L10
```

## Integration with Transformers

The `src/satclip/` package registers `SatCLIPConfig`, `SatCLIPModel`, processors, and pipelines with Transformers `Auto*` classes. The same code is vendored under each model repo's `satclip/` folder for `trust_remote_code=True` loading from the Hub.

```python
import satclip  # registers Auto classes on import
from transformers import AutoModel

model = AutoModel.from_pretrained("path/to/model_repo/SatCLIP-ResNet18-L10")
```
